# NovaTube

Independent video-platform starter for Render.

## Deploy
Static site; publish the repository root. No build step is required.

## Current scope
Responsive discovery UI, category filters, search, demo player, local demo upload entries, likes and comments. Real multi-user accounts, persistent video storage, transcoding, moderation, subscriptions and server-side comments require a backend and object storage; this starter does not claim those production features.
